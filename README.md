# 考公局部关联 0.1.0

独立只读关联插件，使用 Obsidian metadataCache.resolvedLinks，查看一跳入链、出链、名称路径筛选、全库被引用次数或人工 importance 星级排序。引用次数按 Obsidian 解析结果累加，不等于独立题目数量，也不解释为考试概率。不会修改笔记或 YAML。

打开笔记后执行“查看当前笔记局部关联”。“聚焦”将关联笔记设为中心并锁定；顶部开关控制是否固定中心。图形最多 30 个节点，下面的按钮列表包含全部筛选结果并可键盘操作。图中不标箭头，具体方向以列表的入链/出链数据为准。尚未解析或失效的链接未包含。

安装到 .obsidian/plugins/exam-local-links/，重启启用。不替换 Obsidian 原图谱，不依赖其他自制插件。iPad 使用 API 兼容设计但未实测。

当前是固定布局的一跳图，没有拖拽缩放、多跳探索、独立知识树编辑、关系类型建模或图谱与时间轴联动。语法与模拟关系计算测试通过；Obsidian/iPad 实机未验证，全库计算性能也需真实库测量。
